# block-showroom

Tiered voxel object generator — an endless lattice of procedurally generated
"bimoblock" specimens.

## Run it

    npm run serve

then open <http://localhost:8000/>. (Until the module refactor lands you can
also just open `block-showroom.html` in a browser.)

## Test it

    npm test

Runs the Node tests for the pure generation core. Requires Node 18+.
